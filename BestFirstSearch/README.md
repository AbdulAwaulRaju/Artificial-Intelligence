# Best First Search

Best First Search is an informed search algorithm that selects the most promising node based on a heuristic function.

## Time Complexity

- Worst Case: O(n log n)

## Space Complexity

- O(n)

## Explanation

The algorithm uses a priority queue to expand the node with the lowest heuristic value first.

It is commonly used in Artificial Intelligence for pathfinding and graph traversal problems.
